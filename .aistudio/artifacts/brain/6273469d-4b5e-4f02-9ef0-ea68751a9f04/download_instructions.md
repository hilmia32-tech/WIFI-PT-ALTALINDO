# 📲 Unduh Aplikasi Altalindo Portal (APK)

Aplikasi **Altalindo Portal** telah berhasil dibuild dan siap diinstal di HP Android Anda.

---

### 📂 Lokasi File APK di Proyek:
File APK berukuran **~23 MB** telah disimpan dan dapat langsung diunduh dari:
* **`Altalindo-Portal.apk`** *(di root / direktori utama)*
* **`app/build/outputs/apk/debug/app-debug.apk`**

---

### 🚀 Cara Mengunduh di Google AI Studio:

1. **Dari Panel File (Paling Cepat):**
   - Lihat panel file di sebelah kiri layar AI Studio.
   - Temukan file bernama **`Altalindo-Portal.apk`**.
   - **Klik kanan** pada nama file tersebut.
   - Pilih menu **Download**.

2. **Dari Menu Pengaturan AI Studio:**
   - Di bilah menu kanan atas tampilan AI Studio, klik ikon **Settings** / Titik Tiga (`...`).
   - Pilih **Generate / Download APK**.

---

### 📱 Petunjuk Pemasangan di HP Android:
1. Setelah file **`Altalindo-Portal.apk`** terunduh, kirim atau buka file tersebut di HP Android Anda.
2. Jika muncul peringatan *"Aplikasi dari sumber tidak dikenal"*, pilih **Setelan / Settings** lalu aktifkan **"Izinkan dari sumber ini"** (*Allow from this source*).
3. Klik **Instal**.
4. Buka aplikasi, dan saat pertama kali dibuka, pastikan Anda menekan **"Izinkan" (Allow)** pada dialog izin notifikasi agar HP Anda berdering dan memunculkan badge merah saat ada verifikasi masuk!
